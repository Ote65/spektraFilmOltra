### 3.2 数据流关系

```
用户导入 ──▶ I1 拷源(I9权限) ──▶ C11 落工程 ──▶ C8 probe ──▶ I2 显示卡片
                                                                  │
点击卡片 ──▶ I1 select ──▶ C8 probe 缓存 ──▶ I3 AVPlayer 载入原片 ─┘
                                                                  │
暂停/seek ──▶ I1 playerDidPause ──▶ 0.22s 防抖 ──▶ C8 developStill ──▶ C7 render(5 pass) ──▶ I8 叠图
                                                                  ▲
拖动参数 ──▶ I1 applyQuick ──▶ PhotoEdit ──▶ commitEdit ──▶ 清 setupCache ─┘（只重显影当前帧）
                                                                  │
开始渲染 ──▶ I1 renderFull ──▶ C9 export ──▶ C8 逐帧 ──▶ C7 ──▶ 无声 .mov ──▶ C10 mux ──▶ I7 相册
```

### 3.3 状态/依赖约束

| 约束 | 依赖方 | 说明 |
|---|---|---|
| 播放中不显影 | I1 ↔ I3 | `isPlaying=true` 时 I3 只更新 currentTime；I1 取消 stillTask |
| 串帧防护 | I2 | `stillTime` 与 `currentTime` 差 <0.08s 才叠图；`stillRevision` 作过渡 id |
| LUT 缓存失效 | I1 ↔ C8 | 参数改动清 `setupCache[id]`；否则用旧 LUT |
| 音量/背压 | C9 ↔ C10 | 先无声视频再 mux，避免双 input 死锁 |
| 核心冻结 | L0 ← 全体 | 视频不改照片核心数值语义 |
